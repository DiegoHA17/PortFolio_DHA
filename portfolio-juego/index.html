Aplicacion de escritorio

Lunar Finance

Aplicacion de escritorio para gestionar las finanzas personales.

Tauri 2 Rust TypeScript React Vite Notion API Ollama

Capturas del modo demostracion, con datos ficticios.

Problema principal
Apuntar gastos en Notion es cómodo, también desde el móvil, pero saber cuánto se ha gastado y en qué obliga a montar vistas, filtros y fórmulas para cada pregunta. Y un informe presentable no sale solo.
Solucion
Una aplicación ligera con Tauri 2: Rust se encarga de la API de Notion, del token (en el almacén seguro del sistema) y de la conexión con la IA local; TypeScript y React, de la interfaz, los cálculos y los informes. Sin servidor propio ni analíticas.
Funcionalidades
Ingresos, gastos y balance por periodos · categorías con reglas de clasificación automática · pagos periódicos sin duplicados · informes PDF en estilo Clásico o Vintage y exportación a CSV · atajos de iPhone para apuntar gastos desde el móvil · IA local opcional con Ollama que propone categorías y no aplica nada sin confirmación.
Plataformas
Windows 10 y 11, y Linux (.deb, .rpm y AppImage). Versión 0.3.0.

Sistema WordPress a medida para PsicoHito

Psico D

De una pagina web encargada por una clienta a un sistema de gestion WordPress personalizado.

WordPress PHP 8 JavaScript CSS

Capturas de una instalacion de pruebas con datos ficticios.

Evolucion
El encargo era la web de un centro de psicología, y el plan inicial, montar sus páginas con un constructor visual. Como la clienta tenía que poder mantenerla sola, el constructor se sustituyó por un tema propio con paneles de edición por página, un sistema de paletas y un plugin para las solicitudes de cita.
Tema a medida
Paneles de edición para cada página y listas editables (preguntas, servicios, tarifas, profesionales, sedes…) con Subir, Bajar, Duplicar y Eliminar, y una casilla para mostrar u ocultar cada elemento. Registros centrales de servicios y tarifas. Sin constructor visual y sin jQuery.
Identidad visual
Cinco paletas de sistema (una oscura), hasta veinte paletas propias, colores de marca, radios, sombras y un acabado neumórfico opcional. Lo que elige la clienta se valida y llega a la web como variables CSS: nunca escribe CSS.
Citas
Plugin propio para el formulario de solicitud de cita, protegido con nonce, campo trampa y límite de envíos. Panel de citas con estados, confirmación, papelera y resumen en el escritorio de WordPress, adjunto de calendario (.ics) y newsletter.
Responsive
Diseño adaptable con menú móvil en acordeón. El menú de escritorio solo se activa con un puntero que permite hover, así que las tabletas táctiles usan el menú táctil.
